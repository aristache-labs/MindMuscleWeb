# 🏋️ MindMuscle - AI-Powered Fitness Landing Page

A premium, modern, and animated landing page for the revolutionary AI fitness app. Built with the latest web technologies for maximum performance and visual impact.

![MindMuscle Preview](MindMuscleWeb.png)

## ✨ Features

- **Next.js 15** with App Router and TypeScript
- **Tailwind CSS v4.1** with custom theme and dark mode
- **Framer Motion** for premium animations
- **Premium UI Components** with magnetic buttons and scroll effects
- **Responsive Design** optimized for all devices
- **SEO Optimized** with structured data and meta tags
- **Performance Focused** with Lighthouse score > 90

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🏗️ Project Structure

```
src/
```
