# 🚀 MindMuscle Marketing Assets

## 📋 **Quick Start Guide**

This directory contains professional pre-launch marketing assets for MindMuscle's AI-powered fitness platform.

### **🎨 Asset Generator**
Open `social-media-assets.html` in your browser to access the interactive marketing assets generator.

**Features:**
- ✅ **6 Different Asset Types** - Instagram, Twitter, LinkedIn, Stories, Banners
- ✅ **Customizable Text** - Edit messaging in real-time
- ✅ **Brand Consistent** - Uses MindMuscle's official color palette
- ✅ **Professional Quality** - Optimized dimensions for each platform
- ✅ **Interactive Preview** - See changes instantly

### **📥 How to Download Assets**

1. **Open the Generator:** Double-click `social-media-assets.html`
2. **Customize Text:** Use the controls at the top to edit messaging
3. **Preview Assets:** See real-time updates in the preview cards
4. **Download:** Right-click on any preview and "Save image as..."
